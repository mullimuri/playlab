    02 / SINGLE FILE

    외부 파일 없는 게임을 준비해요

    이번 예시는 외부 라이브러리·이미지·음원 요청을 제한해요. AI에게 “외부 파일 없이 모든 코드를 하나의 HTML에 넣어 줘”라고 요청하세요.

    03 / TROUBLESHOOT

    화면이나 소리가 나오지 않나요?

    게임 안의 시작 버튼을 먼저 눌러 보세요. 소리는 기기 설정과 브라우저에 따라 달라요. 화면이 잘리면 “화면 크기에 반응하도록 수정해 줘”라고 AI에게 요청하세요.

    수업용 실행 공간이에요. 직접 만든 코드나 출처를 아는 코드만 실행하세요. 브라우저 기능을 제한한 실행 환경이라 저장·로그인·외부 연결이 필요한 게임은 작동하지 않을 수 있어요. 코드 자체의 오류나 무한 반복까지 해결해 주지는 않아요.
